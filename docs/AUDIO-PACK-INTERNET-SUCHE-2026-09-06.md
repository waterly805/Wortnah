# Wortnah audio pack: Internet suchen

This is the first dedicated manual audio pack for the patient-facing Internet suchen mode. It is separate from Sections 1–4 and avoids the general search-help phrases already reserved in Section 4.

## Production settings

- Folder: `Section-05-Internet-Suchen`
- Voice: use the same selected German voice for every clip.
- Model: `eleven_flash_v2_5`.
- Export: standard MP3.
- Read each phrase naturally, with a short pause after a question.
- Keep the filename exactly as listed; do not add ElevenLabs-generated suffixes.

## Scope note

These clips support common search intents and results controls. Search topics themselves remain text-driven in the app so the patient can search a much larger vocabulary without needing a prerecorded MP3 for every possible subject.
