# Wortnah 0.5.2 visual direction

Date: 10 September 2026

## Reference lock

The user-supplied Wortnah logo is the reference lock: orange painted sun, navy-and-white mountain, hiker silhouette, and the WORTNAH name. The new asset preserves those elements inside one circular badge.

## Interface decisions

- Use the round badge as the only new strong visual accent.
- Keep the existing calm navy, blue, white, and pastel interface around it.
- Keep the accessible text name `Wortnah` next to the image instead of relying on small text inside the badge.
- Retain the tagline as normal page content, where it remains readable.
- Use a single button for the patient field count, showing the current number and a clear accessible next value.
- Let narrow role-card text wrap within its card instead of expanding the page horizontally.

## Quality checks

- The badge remains circular and undistorted at welcome and header sizes.
- The mark is recognizable in the 192px and 512px install assets.
- No additional decorative style competes with the patient choices.
