# Wortnah 0.5.0 live acceptance checklist

## Access

- The public link opens without a workspace sign-in gate.
- Werner, Admin 1, and Admin 2 appear as the only profiles.
- The access-code screen says Step 1 of 2 and accepts Return/Enter or the visible Continue button.
- The daily-PIN screen says Step 2 of 2 and accepts Return/Enter or the visible Sign in button.
- Cancel, clear, backspace, wrong-value retry, and loading states work.

## Werner

- Top controls show Home, field count, audio state, and DE/EN.
- Field count offers only the companion-allowed values from 2/4/6/8/10/12.
- First tap previews audio and the second tap confirms.
- Paging arrows, page dots, Back, Repeat, and Audio remain reachable on a phone.
- Internet search moves through levels and opens the exact final query.
- Recent searches can be heard again and reopened.

## Admin

- Content shows separate Communication and Internet Search tabs.
- Each editor shows the current level, path, and Werner preview.
- A test search entry can be added, edited, hidden, shown, found, and deleted on the intended level.

## Audio

- One approved communication phrase plays its reviewed MP3.
- One approved Internet-search phrase plays its reviewed MP3.
- Repeating a phrase in the same session starts promptly.
- An unavailable server response still speaks through the device voice.

## Layout

- Phone portrait, tablet, and desktop views have no clipped controls or overlapping navigation.
